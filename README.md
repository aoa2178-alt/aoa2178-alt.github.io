# Angel Toki Ade-Oduntan: portfolio

Strategy and operations portfolio: ten working products across AI infrastructure, supply chains, procurement and digital access.

- Live on GitHub Pages: https://aoa2178-alt.github.io
- Also live on Vercel: https://angel-ade-oduntan.vercel.app

Built with React, TypeScript, Vite and Tailwind. `.github/workflows/deploy.yml` builds and publishes the site on every push to `main`.

Run it locally: `npm install`, then `npm run dev`.
